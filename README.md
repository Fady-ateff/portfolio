# Fady Atef Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Personal updates
- Replace `public/Fady-Atef-CV.pdf` when you update your CV. Keep the same filename so the Download CV button continues to work.
- Edit the certificate titles, dates and descriptions in `src/main.jsx` in the `certificates` array.
- Replace the certificate image files in `src/assets/` if you receive updated versions, keeping the same filenames.
- The supplied FA logo is used in the header, footer and favicon. Replace `src/assets/fa-logo.png` and `public/fa-logo.png` together if the logo changes.
